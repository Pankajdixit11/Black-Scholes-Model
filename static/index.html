Black-Scholes Mathematical Foundations

1. Black-Scholes Pricing Formulas

\[ C(S, t) = S e^{-q T} N(d_1) - K e^{-r T} N(d_2) \] \[ P(S, t) = K e^{-r T} N(-d_2) - S e^{-q T} N(-d_1) \]

2. Intermediate Variables (\(d_1\) and \(d_2\))

\[ d_1 = \frac{\ln(S / K) + \left(r - q + \frac{1}{2}\sigma^2\right)T}{\sigma \sqrt{T}} \] \[ d_2 = d_1 - \sigma \sqrt{T} \]

3. The Greeks (Sensitivities)

  • Delta (\(\Delta\)): \(\Delta_{Call} = e^{-qT} N(d_1)\), \(\Delta_{Put} = e^{-qT} (N(d_1) - 1)\)
  • Gamma (\(\Gamma\)): \(\Gamma = \frac{e^{-qT} N'(d_1)}{S \sigma \sqrt{T}}\)
  • Vega (\(\mathcal{V}\)): \(\mathcal{V} = S e^{-qT} N'(d_1) \sqrt{T}\)
  • Theta (\(\Theta\)): Time decay rate per year (divided by 365 for daily decay)
  • Rho (\(\rho\)): Sensitivity to interest rate \(r\)

4. Implied Volatility Solver

Uses Newton-Raphson root finding: \(\sigma_{n+1} = \sigma_n + \frac{C_{market} - C_{model}(\sigma_n)}{\mathcal{V}(\sigma_n)}\) to solve for market implied volatility.
